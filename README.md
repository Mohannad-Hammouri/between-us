# الدخيل

لعبة سهرة زي Among Us، بتنلعب على شاشة كبيرة (لابتوب موصول على التلفزيون) مع الموبايلات.

## طريقة التشغيل
1. افتح رابط الصفحة على اللابتوب (Chrome أفضل)، واكبس «الشاشة الكبيرة».
2. كل لاعب يمسح الكود اللي على الشاشة بموبايله ويدخل.
3. عدد اللاعبين من ٤ لـ ١٢.

- لازم يكون في نت، لأنه الأجهزة بتتصل ببعض عن طريق PeerJS.
- خلّي صفحة الشاشة الكبيرة مفتوحة وقدّام لآخر السهرة، لأنها هي اللي بتشغّل اللعبة.
